Welcome to Project Atlas

Your private workspace for projects, tasks, deadlines, expenses and notes.

Start in three steps

1 · Unzip Download and extract the ZIP. Keep all files together.

2 · Open Double-click index.html on a Windows or Mac computer. Use an up-to-date Chrome, Edge, Safari or Firefox.

3 · Plan Choose Projects → Add project. Set the budget and deadline. Open its card to add tasks, expenses and notes.

Open Project Atlas

How the numbers work

Project progress is completed tasks divided by all tasks linked to that project. Spending is the sum of its logged expenses. Remaining budget is its budget minus spending and can be negative. The Overview shows upcoming tasks due within seven days and incomplete overdue tasks. Timeline moves between past and future months.

Make it yours

Settings offers five light color themes, modern, serif or large text, compact/comfortable/spacious spacing, soft or flat cards and high contrast. You can restore appearance defaults. Choose English, Spanish, French or German for interface labels. Your typed project details stay in the language you entered. Currency selection changes the display symbol; it does not convert amounts.

Save, back up and transfer

Changes save in this browser profile on this device. In Settings choose Download JSON backup regularly. To move devices, copy the backup file, open your customer app there and choose Import JSON backup. Import replaces the records in that browser, after confirmation. Clearing browser/site data or changing browsers can remove local records.

No automatic sync: A project added on your phone will not appear on your laptop until you export and import a backup. The app has no account or shared team database.

Phone and offline use

The extracted download works offline on a desktop computer. For a phone home-screen icon, the customer files first need to be hosted at an HTTPS address. In Safari use Share → Add to Home Screen. In Chrome use Install app/Add to Home Screen if offered. A manifest alone does not provide a private hosted URL. Once hosted and loaded, the offline shell is cached where service workers are supported; keep backups for your records.

If something seems wrong

Blank data: Check that you opened the same browser/profile and URL; import your last backup if needed. Download did not open: Extract the ZIP before opening index.html. Import failed: Select an unmodified Project Atlas JSON backup. Home screen option missing: Use HTTPS in a supported browser and reload once. Records disappeared: Browser data may have been cleared; restore a backup.
