PROJECT ATLAS — QUICK START | HARBORNESTDIGITAL

1. Unzip the download. Keep all files in one folder. Open index.html in Chrome, Edge, Safari or Firefox on a computer.
2. Add a project with start date, deadline and budget. Then add linked tasks, expenses and notes. Check Overview, Budget, Timeline and each project workspace.
3. In Settings choose English, Spanish, French or German interface, currency display, one of five light themes, font, spacing, card style and contrast. The language setting translates interface labels; your own entries are never automatically translated.
4. Export a JSON backup in Settings regularly. Importing replaces the current browser's records. Use backup export/import to move data between devices.
5. Your data stays in this browser profile and device. It does not sync automatically. Clearing browser data can erase records. Currency settings change symbols, not saved amount conversion.
6. Desktop files work offline. To add to a phone home screen, host the app over HTTPS first; a public demo is separate from your private customer copy. On mobile Safari use Share > Add to Home Screen; on Chrome use its Install/Add to Home Screen menu when available.

This is a browser app, not a multi-user cloud service. No login, automatic reminders or shared team database are included. If an import fails, check that the JSON comes from Project Atlas. For help contact HarborNestDigital through your Etsy order.
